# Roadmap

## v0.1 (this repo) — offline-first core
- Auto capture from notifications and SMS, fake-message quarantine, dedup
- Multi-wallet float dashboard with runway prediction and low-float warning
- Manual entry for cash expenses, drawings, capital, recharge, baki, B2B
- One-tap day close with automatic adjustment posting and history
- Commission engine with editable per-operator rates
- Baki ledger with free WhatsApp / SMS reminders
- Daily / monthly / last-month P&L reports
- Bangla + English, JSON backup export/import

## v0.2 — trust and polish (2 to 3 weeks)
- Real operator sample corpus and parser accuracy dashboard (parsed / review / unparsed per day)
- Rate tables served from backend (Supabase) so operator changes do not need an app update
- Recharge card / minute-card inventory
- PDF and Excel export of reports and customer statements
- Home-screen widget with float balances
- App lock (PIN / biometric)

## v0.3 — cloud and growth
- Phone-OTP sign-in, encrypted cloud backup, multi-device sync
- Subscription (bKash / Nagad payment), free tier limits
- Referral program (agent invites agent)
- Staff role with per-staff activity log

## v1.0 — network effects
- Distributor (DSO) dashboard: float requests, agent float heat-map
- Multi-counter owner view
- Anonymised float-demand insights
- iOS companion (read-only dashboard, since iOS cannot read notifications)
